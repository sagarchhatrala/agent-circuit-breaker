# v1.7.0 cleanup and compatibility

Cleanup followed replacement behavior validation. Imports, CLI dispatch, package
entry points, documentation references and regression tests informed the decisions.

| Component | Change | Compatibility evidence |
|---|---|---|
| Generic native scaffold implementation | Replaced by separate Claude/Cursor adapters and project installer | Public function retained; event, merge, repeat-install and restore tests pass |
| Codex/Gemini/Copilot native generation | Retired with explicit migration error | Unverified schemas; regression asserts refusal; Codex guide supplies MCP path |
| Workspace module lookup in host launchers | Replaced with fixed interpreter `-I` invocation | Real module-shadow tests verify attacker module does not run |
| Generic hook UNKNOWN/missing-command continuation | Removed | Only ALLOW continues; malformed payload and stdout/stderr tests cover refusal |
| Automatic catalog extension | Removed | New, removed, changed and malformed definitions quarantine; owner review is hash-bound |
| Long README history | Replaced by concise demo/install/integration/boundary links | Detailed architecture, historical changelog and operational docs retained |
| Duplicate publishing instructions | Replaced by one authoritative workflow guide | Tag dispatch, indexed TestPyPI byte/install checks, identical PyPI promotion |
| Development-only wheel verifier | Superseded before release by wheel-and-sdist downloader | Both indexed files must match the manifest; no public API impact |
| Unused adapter/recorder imports | Removed | Modules and entry points still exercised |

No supported RuntimeGate API, security regression, migration note, license or recovery
documentation was removed. The legacy MCP proxy remains, labeled separately from the
executor-owned path and full Streamable HTTP. RuntimeGate's default event shape stays
compatible; new typed workflows explicitly select compact evidence.

UI assets need no runtime dependency/CDN. Model SDKs, browser automation and recording
tools remain optional or development-only. Recordings, databases, raw traces, browser
profiles and private restoration receipts are excluded from tracked/package content.
The reviewed poster is the sole new source image; videos are release assets.
