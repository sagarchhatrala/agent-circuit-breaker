# v1.0.0 - Stable Release

This release marks the first stable Agent Circuit Breaker release.

## Stable Surface

- Public Python API:
  - `evaluate_action(action, rule_file_path=None)`
  - `validate_rule_file(path)`
  - `rule_schema_metadata()`
  - `Decision`
  - `Rule`
  - `Engine`
- CLI commands:
  - `circuit-breaker check <action>`
  - `circuit-breaker validate-rules <path>`
  - `circuit-breaker -c <action>`
- Decision contract:
  - `ALLOW`
  - `BLOCK`
  - `ERROR`
  - `UNKNOWN`
- External JSON rule schema version `1`.

## Compatibility

The v1.0 compatibility policy is documented in `docs/COMPATIBILITY.md`.

Future patch releases should fix bugs without intentional compatibility breaks. Future minor releases may add compatible safety coverage and result fields.

## Security Notes

Agent Circuit Breaker is a deterministic gate, not a sandbox. Integrations should execute only on `ALLOW` and stop or require review for `BLOCK`, `ERROR`, and `UNKNOWN`.
