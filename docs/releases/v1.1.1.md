# v1.1.1

`v1.1.1` is a safety patch release that addresses externally reported false positives and bypasses in the v1.1 command and SQL coverage.

## Fixed

- Replaced substring-based recursive delete matching with tokenized filesystem operation analysis.
- Fixed false positives for commands such as `transform -rf image.png`, `terraform -rf apply`, and `firm -rf handshake`.
- Blocked split and long-form recursive delete flags:
  - `rm -r -f /etc`
  - `rm --recursive --force /etc`
- Blocked unquoted system path deletion targets such as `rm /etc/passwd`.
- Blocked recursive symbolic world-writable chmod such as `chmod -R a+rwx /tmp`.
- Blocked AWS S3 recursive removal through `aws s3 rm --recursive`.
- Blocked SQL tautological bulk mutations:
  - `DELETE FROM users WHERE 1=1`
  - `UPDATE users SET password='x' WHERE 1=1`
- Fixed SQL block-comment token boundary handling for patterns such as `DROP/**/TABLE users`.

## Added

- Built-in command rules for:
  - disk overwrite or format commands targeting `/dev` devices.
  - root-level `find -delete`.
  - classic shell fork bomb text.
- Regression tests for the externally reported examples.

## Compatibility

- No breaking public API changes.
- No breaking CLI changes.
- No rule schema version change.
- No new runtime dependencies.
