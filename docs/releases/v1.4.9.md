# v1.4.9 - Dependency-Free Pipeline Architecture

Agent Circuit Breaker v1.4.9 adds the first async pipeline architecture for tool-call-level agent safety while preserving the existing CLI and public API behavior.

## Highlights

- Dependency-free `PipelineEngine` with concurrent guard evaluation.
- Fail-closed guard aggregation: a raised guard exception becomes `deny`.
- Immutable `AgentContext`, `GuardResult`, and `PipelineResult` dataclass DTOs.
- Protocol contracts for guards, state stores, hooks, and exporters.
- `AgentCircuitBreaker` SDK with async and sync APIs.
- `StateManager`, `InMemoryStore`, and `SQLiteStore`.
- Guards for shell commands, filesystem paths, network egress, package installs, sequence loops, context-window limits, and tool-call volume.
- Legacy evaluator bridge so the pipeline keeps existing deterministic coverage.

## Intentional Non-Goals

- No Pydantic dependency.
- No Redis adapter.
- No OTel or Prometheus exporter.
- No AST write blocker.
- No claim of OS-level interception for arbitrary `.py` file saves.

File-write validation is supported when an integration routes a proposed write through the SDK/pipeline. Arbitrary editor or filesystem writes require a dedicated editor integration, filesystem proxy, or sandbox.

## Example

```python
from agent_circuit_breaker import AgentCircuitBreaker

breaker = AgentCircuitBreaker(max_context_tokens=120000)
result = breaker.evaluate_tool_call_sync(
    tool_name="shell",
    tool_args={"command": "rm -rf /"},
)

assert not result.allowed
```
