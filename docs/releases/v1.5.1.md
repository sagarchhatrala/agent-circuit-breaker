# v1.5.1 - Pipeline SDK Bypass And DNS Side-Channel Fixes

Agent Circuit Breaker v1.5.1 hardens the pipeline SDK introduced in v1.5.0.

## Fixes

- Fixed arbitrary-key bypasses in the pipeline SDK by recursively inspecting all nested string-valued tool arguments.
- Shell, filesystem, and network guards now see dangerous values even when tool schemas use names such as `shell_line`, `target_path`, or `endpoint`.
- `NetworkEgressGuard` no longer performs live DNS resolution during evaluation, preserving local-first behavior and avoiding DNS-exfiltration side effects.
- Approval records preserve existing `approved` or `denied` decisions when the same action is evaluated again.

## Compatibility

- The default install remains dependency-free.
- Literal private/internal IPs and configured metadata hosts remain blocked.
- Hostname classification is DNS-free by design; environments that require DNS-aware SSRF policy should resolve hostnames in a separate trusted network-control layer.

## Verification

- regressions for arbitrary SDK argument keys
- regression for DNS-free network evaluation
- regression for approval decision preservation
- full unit test suite
- package build
