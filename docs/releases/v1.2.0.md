# v1.2.0

`v1.2.0` is a Phase 1 detection-engine hardening release prepared on the isolated `v2-phase1` branch.

## Added

- Additive `risk_score` fields:
  - top-level result: `risk_score`
  - command analysis: `risk_score`
  - command segments: `risk_score`
  - SQL analysis: `risk_score`
  - SQL statements: `risk_score`
- Unicode normalization before deterministic matching:
  - zero-width character removal
  - Unicode NFKC normalization
  - narrow Cyrillic/Greek homoglyph mapping for risky ASCII tokens
- Structured sandbox bug log: `docs/PHASE1_BUG_LOG.md`
- Phase 1 adversarial tests for quote-splitting, Unicode smuggling, false-positive probes, randomized no-crash fuzzing, and large-input latency.

## Changed

- Shell tokenization now uses Python stdlib POSIX `shlex` parsing for quote removal, quote concatenation, and backslash behavior.
- External rule matcher inputs are normalized before matching while keeping rule schema version 1 unchanged.

## Fixed Reproductions

| `DRO\u200bP TABLE users` | likely `UNKNOWN` | `BLOCK sql_drop_table` |
