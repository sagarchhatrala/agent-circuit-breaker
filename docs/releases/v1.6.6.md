# v1.6.6 - Interpreter, Plugin, and Redaction Hardening

Agent Circuit Breaker v1.6.6 is a targeted hardening release for issues found
through isolated package testing of v1.6.5. It keeps the v1.x public JSON
contract intact while improving detection coverage, plugin authoring, and
persisted-record hygiene.

## Security Improvements

- Blocks dangerous payloads hidden behind additional interpreter execution
  forms, including:
  - `python3 -c "import os; os.system('rm -rf /')"`
  - `perl -e "system(\"rm -rf /\")"`
  - `node -e "require('child_process').execSync('rm -rf /')"`
  - `ruby -e "system(%q{rm -rf /})"`
  - `powershell -EncodedCommand ...`
- Expands default persisted-record redaction for common credential shapes:
  environment-style secret keys, bearer/query tokens, GitHub token prefixes,
  `curl -u` basic auth, `mysql -p...`, and database URL userinfo passwords.

## Plugin Improvements

- Rule-provider plugins may now return declarative rule dictionaries using the
  same schema accepted by JSON rule files.
- Existing providers that return `agent_circuit_breaker.Rule` objects continue
  to work.
- Invalid providers fail closed with entry-point-specific diagnostics so plugin
  authors can debug contract errors.

## Compatibility Notes

- Existing v1.x result fields, schemas, policy files, rule files, audit records,
  approvals, and ledgers remain compatible.
- Some interpreter-wrapped destructive commands that previously returned
  `UNKNOWN` now return `BLOCK`.
- Redaction remains best-effort deterministic hygiene and is not a DLP system.

## Validation

- Full local test suite: `python -m unittest discover` (`514` tests).
- Package build: `python -m build`.
- Isolated local install smoke test from the built wheel.
