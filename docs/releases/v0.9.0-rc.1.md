# v0.9.0-rc.1 - Release Candidate

This prerelease freezes the intended v1.0 surface and adds release-readiness documentation.

## Added

- `docs/COMPATIBILITY.md` covering public API, CLI, decision, rule schema, and behavior compatibility.
- `docs/RELEASE_CHECKLIST.md` covering repeatable version, docs, validation, smoke, git, tag, and GitHub Release steps.
- Documentation regression tests for compatibility and release checklist links and key contract statements.

## Changed

- README, quickstart, roadmap, usage guide, and plan now describe the v0.9 release candidate milestone.
- Package version is now `0.9.0rc1`.
- Package-level API helpers are lazy-loaded so running the CLI module does not pre-import the CLI during package initialization.

## Verification

- `python -m unittest tests.test_docs`
- `python -m unittest discover`
- `git diff --check`

## Notes

- This release candidate is intended to be the final compatibility review point before v1.0.
- The v1.0 release should avoid breaking the public API, CLI, decision, and schema contracts documented here.
