# v1.5.2 - Policy Assurance And Enterprise Hardening

Agent Circuit Breaker v1.5.2 is a feature-bearing hardening release focused on policy assurance while preserving the project scope: deterministic pre-execution enforcement.

## Added

- Added versioned JSON schema artifacts for rule files, policy files, decision output, trajectory output, and audit events.
- Added `circuit-breaker schemas [NAME]` for exporting schema contracts.
- Added fixture-based custom rule tests through `circuit-breaker rules test <PATH>`.
- Added generated built-in rule catalog output through `circuit-breaker catalog`.
- Added architecture boundary tests that keep the core engine, inspectors, and rule loader isolated from optional integrations.
- Added explicit resource limits for rule files, policy files, command text, trajectory files, trajectory action counts, approval payloads, and MCP message traversal.
- Added default redaction of common secret-like values in persisted audit, approval, and run-ledger records.
- Added focused MCP conformance coverage for deeply nested tool-call arguments.

## Changed

- Local persisted records now include redaction metadata.
- Raw persisted record retention requires explicit `ACB_RETAIN_RAW_RECORDS=1`.
- Compatibility docs now reflect the current v1.x rule schema, including regex, composite matchers, approval responses, and HMAC signatures.

## Compatibility

- The default install remains dependency-free.
- Existing CLI and API result fields remain additive and backward compatible.
- Built-in blocks still take precedence over custom allow rules.
- Oversized policy inputs now fail closed instead of being parsed.
