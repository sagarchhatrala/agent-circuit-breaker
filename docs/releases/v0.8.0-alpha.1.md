# v0.8.0-alpha.1 - Security Documentation Alpha

This prerelease documents the project security model, threat model, and recommended integration patterns.

## Added

- `docs/SECURITY_MODEL.md` covering trust boundaries, decisions, rule ordering, fail-closed behavior, local-first operation, and explicit non-goals.
- `docs/THREAT_MODEL.md` covering in-scope threats, out-of-scope threats, assumptions, and residual risk.
- `docs/INTEGRATION_GUIDE.md` covering CLI gate usage, Python API gate usage, rule validation, `UNKNOWN` handling, placement, and logging.
- Documentation regression tests for security docs and docs-index links.

## Changed

- README, quickstart, roadmap, usage guide, and plan now describe the v0.8 security documentation milestone.

## Verification

- `python -m unittest tests.test_docs`
- `python -m unittest discover`
- `git diff --check`

## Notes

- Agent Circuit Breaker is explicitly documented as a deterministic gate, not a sandbox.
- Production integrations should execute only on `ALLOW` and stop or review all other outcomes.
