# v1.6.7 - OpenSSF Baseline Readiness

Agent Circuit Breaker v1.6.7 is a repository governance and supply-chain
hardening release focused on defensible OpenSSF Baseline Level 1 readiness.

## Added

- OpenSSF Baseline Level 1 evidence matrix in `docs/OPENSSF_BASELINE_1.md`.
- GitHub security configuration guide with verified repository settings and
  manual account/org actions in `docs/GITHUB_SECURITY_CONFIGURATION.md`.
- Root `CONTRIBUTING.md` with setup, review, testing, security-sensitive
  contribution, and generated-artifact guidance.
- `docs/GETTING_STARTED.md` for a concise installation and first-evaluation
  path.
- Dependabot configuration for GitHub Actions and Python packaging metadata.

## Changed

- `SECURITY.md` now points directly to private vulnerability reporting and
  documents the supported v1.x security-fix policy.
- Release documentation now includes OpenSSF/security hygiene checks.

## Verification

This release should be validated with:

```bash
python -m unittest discover
git diff --check
python -m build
python -m twine check dist/agent_circuit_breaker-1.6.7.tar.gz dist/agent_circuit_breaker-1.6.7-py3-none-any.whl
```

## Compatibility

No runtime API, CLI, rule schema, policy, MCP, pipeline, approval, audit, or
ledger behavior changes are intended in this release. The changes are limited
to repository governance, GitHub setting verification, packaging metadata versioning, and
documentation.
