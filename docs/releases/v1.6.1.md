# v1.6.1 - Policy Source Trust And Command Name Alignment

Agent Circuit Breaker v1.6.1 adds fail-secure repository policy trust handling and
aligns the project-facing command names on the full package name.

## Added

- Added policy source metadata for loaded policies.
- Added fail-secure validation for auto-discovered repository policy.
- Added `--trust-repository-policy` for explicitly trusting repository policy that
  can weaken controls.
- Added regression tests for repository policy strengthening, weakening rejection,
  explicit policy loading, and trusted repository override behavior.

## Changed

- Updated the primary console command to `agent-circuit-breaker`.
- Updated the MCP proxy command to `agent-circuit-breaker-mcp-proxy`.
- Updated documentation, examples, tests, release checklist references, and help
  text to use the full command names.
- Auto-discovered repository policy may strengthen enforcement by default, but it
  cannot add allow rules, select advisory mode, select the solo profile, or
  disable strict mode unless explicitly trusted.

## Compatibility

- Explicit `--policy` paths and `ACB_POLICY` remain caller-selected policy sources.
- Built-in blocks still take precedence over custom allow rules.
- Existing Python APIs remain compatible.
- The default install remains dependency-free.
