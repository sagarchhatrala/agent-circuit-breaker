# v1.6.4 - Decision Contract Consistency

Agent Circuit Breaker v1.6.4 is an incremental security-consistency release. It
does not change the v1.x public JSON contract, rule schema, CLI command names, or
dependency-free default install.

## Security Improvements

- Adds an internal canonical decision contract so adapters can derive security
  meaning from one compact representation.
- Keeps `ALLOW` as the only executable decision state. `BLOCK`, `UNKNOWN`,
  `ERROR`, and `PENDING_APPROVAL` remain stop states.
- Rejects `http://` remote policy URLs by default. Use HTTPS, or explicitly pass
  `--allow-insecure-remote-policy` when a caller intentionally accepts cleartext
  policy transport risk.
- Adds approval revalidation for freshly evaluated results. Approval records do
  not bypass fresh evaluation; they must match the current action, policy,
  coverage, validation, and expiry context.

## MCP And Trajectory Consistency

- MCP coverage now distinguishes security-relevant `tools/call` inspection from
  protocol messages where inspection is not applicable.
- Stateful MCP trajectory checks now expose attempted-versus-forwarded counts so
  blocked calls are visible as attempted but not forwarded.
- Trajectory results include an additive `run_fingerprint` based on canonical
  JSON serialization. Existing `run_id` remains unchanged for compatibility.
- Per-action trajectory entries include compact canonical decision summaries for
  replay and audit consistency.

## Evidence And Governance

- Audit events and run-ledger replay include canonical decision summaries.
- Cross-adapter regression coverage verifies equivalent security semantics across
  API, MCP, trajectory, and pipeline-adjacent result projections.

## Compatibility Notes

- Existing v1.x result fields keep their meaning.
- `http://` remote policies now require explicit opt-in. `https://` remote
  policies and local policies continue to work as before.
- New fields are additive: `canonical_decision`, `run_fingerprint`, MCP
  `security_relevant`, and MCP `trajectory_state`.

## Validation

- Full local test suite: `python -m unittest discover`.
- Package build: `python -m build`.
