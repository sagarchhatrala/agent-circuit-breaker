# v1.6.8 - MCP Supply-Chain And Result Hardening

Agent Circuit Breaker v1.6.8 is a compatible MCP hardening release. It expands
the MCP proxy from request-only argument inspection into catalog, result, and
cross-tool secret-flow protection while preserving the existing v1.x decision
contract.

## Added

- MCP `tools/list` catalog pinning for tool name, description, and input schema
  fingerprints.
- MCP catalog quarantine for changed tool definitions and unsafe tool
  descriptions.
- MCP `tools/call` result inspection for prompt-injection-like returned text
  before it reaches the agent context.
- Hash-only cross-tool secret taint tracking for credential-shaped values
  returned by one tool and later relayed into another tool.
- Minimal dependency-free HTTP JSON-RPC MCP proxy mode with `--http-listen` and
  `--http-upstream`.
- Native hook scaffolds for Claude, Cursor, Codex, Gemini, and Copilot user
  hook config formats.
- One-shot hook drift helpers for detecting and restoring removed ACB hook
  entries.

## Security

- Added command detection for reverse shells.
- Added command detection for environment or credential material sent to
  network sinks.
- Added command detection for write/delete/move/copy access to common
  credential paths.
- Added SQL functional-tautology detection for update patterns such as
  `SET flag = true WHERE flag = false`.

## Compatibility

- Existing v1.x public result fields, rule schema, policy schema, approval
  records, audit records, and trajectory output keep their meaning.
- Existing `cat .env` single-action behavior remains compatible; read-only
  secret access is not newly blocked unless it is paired with egress or appears
  in an MCP cross-tool taint flow.
- Some previously unclassified MCP catalog changes, tool-result prompt
  injection payloads, reverse shells, credential-to-network commands, and
  functional SQL tautologies now fail closed.
