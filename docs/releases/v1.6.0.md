# v1.6.0 - Typed Decision Foundation

Agent Circuit Breaker v1.6.0 starts the v1.6 architecture line by adding typed
decision evidence while preserving the existing v1.x CLI and Python API
contracts.

## Added

- Added `EvaluationRequest` for normalized action request metadata.
- Added `DecisionResult` for typed verdicts, reasons, findings, policy source,
  evaluation IDs, fail-secure status, and risk score.
- Added `Finding` for structured rule evidence with rule ID, domain, pack ID,
  severity, message, and audit-safe evidence.
- Added deterministic conversion from existing public result dictionaries into
  typed decision results.
- Added legacy dictionary round-tripping through `DecisionResult.to_legacy_dict()`.
- Added focused regression tests for typed block, unknown, error, evaluation ID,
  and public export behavior.

## Changed

- `evaluate_action(...)` now routes successful and fail-closed rule-file error
  results through the typed decision model internally before returning the stable
  public dictionary.
- Package exports now include `EvaluationRequest`, `DecisionResult`, and
  `Finding`.
- Architecture, API, JSON contract, roadmap, and README documentation now describe
  the typed decision foundation.

## Compatibility

- Existing CLI text output is unchanged.
- Existing CLI JSON output is unchanged by default.
- Existing `evaluate_action(...)` dictionary output is unchanged.
- Existing rule files, policy files, signatures, audit, approval, ledger, MCP, and
  pipeline behavior remain compatible.
- The default install remains dependency-free.
