# v1.1.2

`v1.1.2` is a safety patch release that addresses follow-up adversarial variants found after the `v1.1.1` safety patch.

## Fixed

- Generalized shell fork-bomb detection beyond the exact colon-function form:
  - `f(){ f|f& };f`
  - `bomb(){ bomb|bomb& };bomb`
- Expanded `find -delete` detection for protected path children and trailing-slash roots:
  - `find /etc/ -delete`
  - `find /home/someuser -delete`
- Blocked AWS S3 bucket removal:
  - `aws s3 rb s3://bucket --force`
- Expanded recursive symbolic world-writable chmod detection:
  - `chmod -R u+rwx,g+rwx,o+rwx /tmp`
  - `chmod -R ugo+rwx /tmp`

## Compatibility

- No breaking public API changes.
- No breaking CLI changes.
- No rule schema version change.
- No new runtime dependencies.
