# Agent Circuit Breaker v1.6.9

Date: 2026-10-15

Version 1.6.9 narrows and strengthens the supported production story around a
single-host, trusted RuntimeGate deployment. It adds durable local runtime
state, executor-bound authorization consumption, audit checkpoints, readiness
checks, and a safe local validator while preserving the advisory CLI/API
contracts from earlier 1.x releases.

## Security

- Added `RuntimeGate` and `RuntimeToolExecutor` for trusted integrations that
  need one-action-at-a-time authorization before synthetic or real side
  effects.
- Added durable `SQLiteRunStore` support with schema metadata, integrity
  validation, unresolved-execution detection, restart behavior, approval
  consumption, reconciliation, suspension, revocation, and single-use
  authorization checks.
- Added HMAC-aware audit checkpoints through `timeline --checkpoint` and
  `timeline --verify --checkpoint`.
- Added `production-check` for the supported local-runtime deployment scope.
- Added `safe-validate` for local synthetic validation of allowed execution,
  denied execution, approval replay resistance, audit checkpoints, and
  readiness checks.

## Fixes

- `production-check` fails if the configured runtime SQLite store is missing
  instead of creating a new empty database and treating it as healthy.
- `safe-validate` refuses to overwrite pre-existing managed artifacts in its
  evidence directory.

## Documentation

- Clarified that ACB is not an OS sandbox, distributed coordinator, or
  arbitrary-agent containment system.
- Added runtime hardening, principal/capability, adapter enforcement, and
  production-readiness documentation for the supported RuntimeGate boundary.

## Compatibility

- Existing CLI/API decision fields remain additive.
- The new production readiness verdict is intentionally scoped to
  single-host RuntimeGate deployments and must not be interpreted as general
  production readiness for every adapter or execution path.
