# v1.1.0

`v1.1.0` adds compatible safety coverage and integration documentation while preserving the v1.0 public API, CLI, decision contract, and external rule schema version 1.

## Added

- Built-in command rules for:
  - package publish commands without explicit release context.
  - destructive Docker command shapes.
  - cloud resource deletion command shapes.
  - forceful Kubernetes deletion command shapes.
- Detailed JSON output contract documentation in `docs/JSON_OUTPUT_CONTRACT.md`.
- Local allowlist pattern documentation in `docs/ALLOWLIST_PATTERN.md`.
- Allowlist example rule file and Python example under `examples/`.

## Changed

- Known dangerous command rules can return `BLOCK` even when heuristic SQL parsing also reports an unrelated shell-glob parsing error.
- Roadmap and docs index now mark v1.1 as released.

## Compatibility

- No breaking public API changes.
- No breaking CLI changes.
- No rule schema version change.
- No new runtime dependencies.

## Verification

- `python -m unittest discover`
- `git diff --check`
- `python -m build`
- `python -m twine check dist/*`
