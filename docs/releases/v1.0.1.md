This patch release prepares the project for TestPyPI and PyPI publishing.

## Added

- `pyproject.toml` build-system declaration.
- Publishing guide in `docs/PUBLISHING.md`.
- Publishing steps in `docs/RELEASE_CHECKLIST.md`.

- Package metadata now includes README long description and project URLs.
