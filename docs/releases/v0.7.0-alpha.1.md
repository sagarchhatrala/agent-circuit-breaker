# v0.7.0-alpha.1 - Adversarial Test Alpha

This prerelease adds adversarial regression coverage and tightens fail-closed handling for malformed parser inputs.

## Added

- Adversarial test suite covering hostile command chains, malformed command input, malformed SQL input, SQL comments and quotes, blank actions, non-string API input, invalid custom rule handling, unsupported rule features, and deterministic repeated evaluations.
- Newline-separated command chain inspection.

## Changed

- Malformed command analysis now returns an `ERROR` verdict instead of falling through to `UNKNOWN`.
- Malformed SQL analysis now returns an `ERROR` verdict instead of falling through to `UNKNOWN`.
- README, quickstart, roadmap, usage guide, and plan now describe the v0.7 adversarial testing milestone.

## Verification

- `python -m unittest tests.test_adversarial`
- `python -m unittest discover`
- `git diff --check`

## Notes

- This release does not claim complete shell or SQL grammar support.
- The milestone focuses on deterministic fail-closed behavior for known malformed inputs and regression coverage for the existing supported surface.
