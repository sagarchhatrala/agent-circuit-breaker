# v0.6.0-alpha.1 - Public API Alpha

This prerelease adds the first public Python API for integrations that want deterministic safety checks without invoking the CLI.

## Added

- `agent_circuit_breaker.api` module.
- Package-level `evaluate_action(action, rule_file_path=None)`.
- Package-level `validate_rule_file(path)`.
- Package-level `rule_schema_metadata()`.
- Public API reference in `docs/API.md`.
- API tests covering built-in blocks, known safe allows, unknown results, custom rule enforcement, invalid rule fail-closed behavior, rule validation, and schema metadata.

## Changed

- README, quickstart, roadmap, usage guide, and plan now describe the v0.6 public API milestone.

## Verification

- `python -m unittest tests.test_api`
- `python -m unittest discover`
- `git diff --check`
- Python API smoke checks for built-in and custom-rule evaluation

## Notes

- The API is alpha but intentionally small.
- Invalid custom rule files fail closed with an `error` verdict.
- The CLI behavior remains supported and unchanged.
