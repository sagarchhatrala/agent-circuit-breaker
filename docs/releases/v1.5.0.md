# v1.5.0 - Optional Enterprise Pipeline Integrations

Agent Circuit Breaker v1.5.0 builds on the dependency-free pipeline foundation from v1.4.9 with optional integrations for distributed state, observability, benchmarking, and stronger package-install policy inputs.

## Highlights

- Pipeline guard scheduling now uses `asyncio.TaskGroup` with fail-fast cancellation.
- Optional `RedisStore` provides distributed circuit state with atomic Lua-script transitions.
- Optional `OTelExporter` and `PrometheusExporter` subscribe to pipeline events.
- `benchmark_pipeline(...)` reports integration-specific timing summaries without hard-coded latency claims.
- `PackageInstallGuard` can enforce transitive allowlists from caller-supplied resolved dependency metadata or lockfiles.
- The default install remains dependency-free.

## Optional Extras

```bash
python -m pip install "agent-circuit-breaker[redis]"
python -m pip install "agent-circuit-breaker[otel]"
python -m pip install "agent-circuit-breaker[prometheus]"
python -m pip install "agent-circuit-breaker[enterprise]"
```

## Compatibility

- Existing CLI commands and public Python APIs remain supported.
- The core package still has `install_requires=[]`.
- Pydantic DTOs, AST write blocking, and arbitrary editor/filesystem write interception are not included in this release.
