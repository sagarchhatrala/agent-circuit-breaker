# v0.4.0-alpha.1 Release Notes

Release type: alpha prerelease

Tag: `v0.4.0-alpha.1`

Package version: `0.4.0a1`

## Summary

`v0.4.0-alpha.1` adds safe external JSON rule loading, validation, and optional custom rule enforcement. The release keeps custom rules deterministic: rule files are data only, cannot execute arbitrary code, and support only a small matcher set.

## Added

- External rule definition validator.
- JSON rule file loader with explicit errors for:
  - missing files
  - directory paths
  - invalid JSON
  - non-object top-level JSON
  - invalid rule definitions
- CLI rule validation command:

```bash
circuit-breaker validate-rules docs/examples/rules/custom_deploy_guard.json
```

- Safe rule construction for deterministic matcher types:
  - `contains`
  - `equals`
  - `prefix`
- Optional custom rule enforcement:

```bash
circuit-breaker check "deploy production" --rules docs/examples/rules/custom_deploy_guard.json
```

- Fixture-style JSON rule example:
  - `docs/examples/rules/custom_deploy_guard.json`

## Changed

- Package version bumped from `0.3.0a1` to `0.4.0a1`.
- Documentation updated from v0.3 SQL safety alpha to v0.4 external rule validation alpha.
- Roadmap updated to mark v0.4 as released.

## Safety Behavior

Invalid custom rule files fail closed. If a `--rules` file is invalid, command evaluation stops and the CLI returns exit code `1`.

Built-in rules are evaluated before custom rules. A custom `allow` rule cannot override built-in filesystem, command, or SQL block rules.

## CLI Examples

Validate a custom rule file:

```bash
circuit-breaker validate-rules docs/examples/rules/custom_deploy_guard.json
# Valid: TRUE
```

Use a custom rule file during command checks:

```bash
circuit-breaker check "deploy production" --rules docs/examples/rules/custom_deploy_guard.json
# Verdict: BLOCK
# Matched Rule: custom_deploy_guard
```

Built-in rules still block first:

```bash
circuit-breaker check "rm -rf /" --rules docs/examples/rules/custom_deploy_guard.json
# Verdict: BLOCK
# Matched Rule: fs_recursive_delete
```

## Limitations

- This is an alpha release.
- External rule files support JSON only.
- External rule files support only `contains`, `equals`, and `prefix` matchers.
- External rule files cannot execute arbitrary Python code.
- Remote rule fetching, rule signing, YAML, and advanced matcher expressions are not included.
- Agent Circuit Breaker is not a sandbox, antivirus, endpoint monitor, or process isolation tool.
