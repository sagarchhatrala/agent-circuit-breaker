# Companion Products

This folder contains companion products and tools that complement Agent Circuit Breaker.

## Product Ideas

1. **Rule Validator CLI** — Validate rule files before deployment
2. **Log Analyzer** — Retrospective safety audits of agent actions
3. **Rule Library** — Community-contributed rule templates and examples

## Timeline

These products develop in parallel after Agent Circuit Breaker v0.1 is complete.
