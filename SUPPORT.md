# Support

Agent Circuit Breaker is maintained as an open-source project.

Use GitHub issues for:

- reproducible bugs;
- documentation gaps;
- feature requests with a clear use case;
- questions about supported integration boundaries.

Do not use public issues for vulnerabilities. Follow `SECURITY.md` and use
GitHub private vulnerability reporting.

The project does not provide guaranteed response times or private operational
support. Include the package version, Python version, operating system,
minimal reproduction steps, and expected versus actual behavior when filing an
issue.
