# Code of Conduct

This project follows a simple standard for participation: be respectful,
specific, and constructive.

Maintainers may moderate or remove comments, issues, pull requests, or other
contributions that include harassment, personal attacks, spam, credential
disclosure, intentionally unsafe instructions, or repeated off-topic content.

Security reports should be handled through the private reporting process in
`SECURITY.md`, not through public argument or disclosure before a fix or
mitigation is available.
